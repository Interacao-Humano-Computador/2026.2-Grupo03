## 1. Introdução

A lista de verificação sugerida no Plano de Ensino vai até a Entrega 4 (SALES, 2026, pp. 8–13). Para as Entregas 5 a 8, esta página registra o que já se sabe: o tema e o prazo de cada entrega, as listas que o grupo ou cada integrante precisa elaborar e as inspeções previstas. Quando o professor publicar as listas no Moodle, elas devem ser transcritas aqui, no formato das [Entregas 1 a 4](../../docs/entrega-1/verificacao/listas.md).

Até lá, uma forma de verificar as entregas é aplicar os itens do desenvolvimento do projeto (D1 a D11, Quadro 2 da [Entrega 1](../../docs/entrega-1/verificacao/listas.md)), que se repetem em todas as listas das Entregas 2 a 4. Isso é uma sugestão do grupo, não uma exigência do Plano.

## 3. Entrega 8: modelo para a verificação dos artefatos

Os materiais de consulta do grupo incluem um modelo de lista de verificação da qualidade de artefatos, indicado para as inspeções e para a Entrega 8. O modelo usa as colunas Item, Descrição, Avaliação (Conforme / Não conforme / Não se aplica), Descrição do problema, Sugestão de ação corretiva e Observações. Os 12 itens gerais do Quadro 2 valem para qualquer artefato; os demais itens do modelo tratam de estórias de usuário e não se aplicam ao projeto.

**Quadro 2 – Itens gerais do modelo de lista de verificação da qualidade de artefatos**

| Item | Descrição |
| :---: | --- |
| 1 | O documento está na última versão do template? |
| 2 | O nome do documento possui nomenclatura de acordo com o padrão definido? |
| 3 | A versão do documento foi incrementada e a descrição da elaboração ou alteração foi registrada no histórico de revisões do documento? |
| 4 | O documento possui cabeçalhos e rodapés atualizados? |
| 5 | No caso de artefato ainda não homologado pela área de negócio, está na versão 1.0? |
| 6 | A versão do documento é equivalente à versão e data do histórico? |
| 7 | O documento possui formatação geral seguindo o template? (Título, estilo, fontes e indentação) |
| 8 | O documento possui erros de pontuação ou gramática? |
| 9 | O documento está registrado no repositório na pasta seguindo a diretriz de qualidade de projeto? |
| 10 | Todos os textos auxiliares (azul entre chaves "[]") foram retirados? |
| 11 | Todos os textos de exemplo foram retirados? |
| 12 | Os itens que não foram utilizados no documento possuem o texto "Não se aplica"? |
