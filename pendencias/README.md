# Pendências do Grupo 03

Esta pasta reúne **tudo o que ainda falta** no site do projeto de IHC. Nada do que está aqui aparece no site: as páginas publicadas mostram só o que já está pronto, e cada lacuna encontrada na revisão de 17/10/2026 foi registrada nestes arquivos, com a página, o responsável (quando registrado) e a evidência.

## Como usar

1. Escolha um item, faça a correção na página indicada (em `docs/`) e acrescente uma linha no histórico de versões da página, com autor e revisor.
2. Apague o item do arquivo de pendências no mesmo commit.
3. Itens da seção "Decisões a confirmar" de cada arquivo pedem só a confirmação do grupo: se a decisão estiver certa, basta apagar o item; se não, corrija a página.
4. Antes de publicar, rode `mkdocs build --strict` para conferir links e navegação.
