## Objetivo 0

**Identificar como iniciar e acompanhar a renovação da CNH no portal e nos canais oficiais.**

Este HTA representa uma **hipótese inicial de percurso**, não uma descrição validada do processo oficial vigente. Deve ser confrontado com o portal e com usuários antes da inspeção.

| Tarefa | Subtarefas |
| --- | --- |
| 1. Localizar informação | 1.1 Acessar o portal; 1.2 localizar a área de habilitação; 1.3 buscar renovação |
| 2. Entender exigências | 2.1 Ler documentos e requisitos; 2.2 verificar necessidade de exames; 2.3 identificar condições especiais |
| 3. Identificar onde executar | 3.1 Consultar canais oficiais; 3.2 verificar etapas online ou presenciais; 3.3 descobrir como marcar atendimento quando aplicável |
| 4. Prosseguir no canal indicado | 4.1 Seguir orientações oficiais; 4.2 guardar comprovantes ou referências disponíveis |

**Plano 0:** realizar 1 → 2 → 3 → 4. **Plano 2:** executar 2.1 e 2.2 e, se pertinente, 2.3. **Plano 3:** consultar 3.1 e 3.2; executar 3.3 somente se a etapa exigir atendimento agendado.

**Pontos a investigar:** descoberta do serviço, compreensão da documentação, transição entre canais e certeza sobre a próxima etapa.
