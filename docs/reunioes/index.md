# Reunioes

Este diretorio concentra as atas das reunioes da equipe. Crie uma nova ata copiando `docs/templates/reuniao/_template.md` e use o formato `AAAA-MM-DD-nome-curto.md`.

## Indice de atas

| Data         | Objetivo            | Participantes | Ata               | Video              |
| ------------ | ------------------- | ------------- | ----------------- | ------------------ |
| _dd/mm/aaaa_ | _Objetivo resumido_ | _Nomes_       | _Link para a ata_ | _Link nao listado_ |

As gravacoes devem ser hospedadas como **nao listadas** e compartilhadas apenas com as pessoas autorizadas.
