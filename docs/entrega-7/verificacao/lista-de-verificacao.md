Esta lista guia as inspeções da Entrega 7 (Relato dos resultados do protótipo de alta fidelidade): a do próprio Grupo 03 e a do Grupo +1, prevista para 16/11/2026 (transcrição das atividades do Moodle). O Plano de Ensino traz a lista de referência só até a Entrega 4 (Sales, 2026, pp. 8–13). Por isso, os itens do desenvolvimento do projeto (Seção 2) são os mesmos da Entrega 1, e os itens de conteúdo (Seção 3) são **propostos pelo grupo**, a partir das fontes que o relatório já cita. Eles devem ser confirmados quando o professor publicar uma lista própria para a Entrega 7 no Moodle. **[VERIFICAR: se o Moodle traz lista de verificação para a Entrega 7]**

**Como usar.** Para cada item, responda **Sim**, **Não** ou **Incompleto** no quadro de registro do grupo inspecionado (Seção 4), anote a evidência (link da página ou minuto do vídeo) e registre a versão, a data e a hora da avaliação.
