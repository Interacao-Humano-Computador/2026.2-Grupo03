## 1. Introdução

Esta página reúne as listas de verificação da Entrega 2 (Perfil do usuário, Aspectos Éticos de Pesquisas Envolvendo Pessoas e Análise de Tarefas): a lista do Plano de Ensino (seção 2), a lista que a monitoria aplicou ao site do Grupo 03 (seção 3), as listas que o grupo elaborou ou precisa elaborar (seção 4) e as aplicações registradas (seção 5).

Nesta entrega o professor pediu, além da lista sugerida, que o grupo construísse **listas próprias para cada artefato**: "A ou as listas de verificação devem possuir alguns itens, no mínimo 3, para verificar os seguintes artefatos" (SALES, [2026], p. 1). A monitoria cobrou essas listas, com quantidades mínimas maiores, e registrou que o grupo fez "uma lista de verificação geral para todos os artefatos, mas o certo é que seja uma lista para cada artefato" (SILVA, 2026, p. 4, OBS 11).
